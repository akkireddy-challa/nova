# Cross-Team Requests & Blockers

Use this log when an agent needs changes in files owned by another agent, or when blocked.

Format:
```markdown
### [YYYY-MM-DD] @target-role from @requesting-role
- **Need**: Description of change/interface required.
- **Affected Files**: list of files.
- **Status**: [open|in-progress|resolved]
- **Resolution**: details when done.
```
